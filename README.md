# CS300 8-1 Journal
The main problem I solved in these projects was how to efficiently store, organize, and retrieve course data for an advising system while also printing the courses in alphanumeric order. This required not only writing working code, but also analyzing which data structure would perform best in terms of run-time and memory usage. Through comparing vectors, hash tables, and binary search trees (BSTs), I determined that a BST was the most appropriate solution because it maintains sorted order automatically and allows efficient insertion, searching, and traversal. Understanding data structures was critical to this process because each structure has trade-offs. For example, vectors are simple but require additional sorting, and hash tables are fast for lookups but do not maintain order. This analysis helped guide my decision and ensured that my final program was both efficient and functional for academic advisors' needs.

While working through the project, I encountered several roadblocks, particularly with file input and ensuring the program correctly loaded and displayed course data. I overcame these issues by debugging step by step, validating file formats, and refining how the program handled user input and missing data. This process strengthened my problem-solving skills and reinforced the importance of testing and iteration. Overall, this project expanded my approach to software design by showing me the value of planning before coding, especially when selecting data structures. It also improved how I write maintainable, readable, and adaptable programs. I focused on organizing my code into clear sections (such as structs, classes, and functions), using meaningful variable names, and separating logic into reusable components. As a result, my code is easier to understand, modify, and extend in the future, which is essential for real-world software development.
